# Super Laboratory Services — website redesign

A responsive static website concept for Super Laboratory Services, using the publicly visible service scope from https://superlabs.co.za/.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive design, colors, typography, layout
- `script.js` — mobile navigation, current year, and email-enquiry form behavior

## Preview locally
Open `index.html` in a modern browser. Google Fonts are loaded from Google Fonts when internet access is available; system sans-serif fallbacks are included.

## Contact form behavior
The form validates required fields and opens the visitor's default email app with a draft addressed to `slsqc@superlabs.co.za`. It does not send data to a server or store submitted information. A production site that needs true online form submission should connect a secure server-side form handler or an approved form service.

## Before publishing
1. Confirm that all service descriptions are accurate and approved by Super Laboratory Services.
2. Add verified telephone number, physical address, operating hours, certifications/accreditations, turnaround times, sample submission instructions, and privacy details only after the business confirms them.
3. Test keyboard navigation, mobile layouts, links, form behavior, and performance.
4. Configure HTTPS, domain/DNS, hosting, redirects, backups, analytics (if desired), and search-engine metadata in the production environment.
5. Replace the existing site files only after backing them up and confirming the current hosting/CMS workflow.

## Access required to publish
The redesign package alone does not change the live website. Publishing requires authorized access to the site's hosting account or deployment repository/CMS, and DNS access only if hosting or domain routing must change. No credentials are included in this package.
